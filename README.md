## চালু করার ধাপ

1. [Firebase Console](https://console.firebase.google.com)-এ নতুন প্রজেক্ট খুলুন (Google Analytics বন্ধ রাখুন)।
2. **Build → Realtime Database → Create database** (লোকেশন: Singapore)। **Locked mode** বেছে নিন।
3. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable**।
4. **Realtime Database → Rules** ট্যাবে `database.rules.json`-এর পুরো লেখা বসিয়ে **Publish** দিন।
5. **Project settings (⚙️) → General → Your apps → Web (`</>`)** যোগ করুন। যে `apiKey` ও `databaseURL` দেখাবে সেগুলো `index.html`-এ বসান:
   ```js
   const FIREBASE_SHARDS = {
     main: { apiKey: "AIza...", databaseURL: "https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app" }
   };
   ```
   (এগুলো গোপন চাবি নয়; নিরাপত্তা আসে Rules থেকে। তাই Rules অবশ্যই বসাবেন।)
6. `index.html` ও `logo.png` GitHub রিপোজিটরিতে আপলোড করে **Settings → Pages**-এ `main` / `root` দিন।
